# 选课指南 · 使用说明

> 面向使用「选课指南」 skill 的同学。

## 这个 skill 能做什么

**选课指南**帮你在选课季做出有证据的决策——不靠道听途说，靠同学们真实提交的课程评价 + 一套选课方法论。

| 场景 | 你可以这样说 |
|---|---|
| 查具体课程 | 「微积分哪个老师好」「线性代数避雷」「程序设计基础怎么样」 |
| 查具体老师 | 「艾颖华怎么样」「艾老师给分好吗」（支持"X老师"简称） |
| 多门课 / 多位老师对比 | 「微积分和线性代数哪个好」「艾老师和杨老师怎么选」 |
| 求推荐 / 做规划 | 「下学期帮我选课」「秋季求稳怎么选」「暑假想选两门轻松的」 |
| 看全库总览 | 「总览」「全部课程排行」 |
| 问课程归属 | 「概率论什么时候上」 |
| 聊方法论 | 「怎么判断一门课值不值得选」「学期很满怎么排课」 |

支持**多轮追问**：比如先发「帮我选课」，它会一次性问清三件事——**哪个学期、目标导向（保 GPA / 兴趣打基础 / 学期已满求轻）、有没有已锁定不想动的课**——然后按你的约束给建议；已锁定的课会自动从推荐里排除。

## 快速上手示例

**示例 1：查一门课**

> 你：微积分哪个老师好
>
> 它：给出每个「课 + 老师」的均分、评价条数、评论里的关键事实（作业次数、考试形式、给分），再按「求稳 / 想学东西 / 学期已满」分别给建议，最后附风险提示（样本量、给分年际波动等）。

**示例 2：做整学期规划**

> 你：帮我选课
>
> 它：追问三个约束（学期 / 目标 / 已锁定课程）
>
> 你：秋季，保GPA，线代锁了
>
> 它：排出秋季有评价的课程表（自动排除线代），按保 GPA 目标给建议，并生成一份 **markdown 报告附件**，可直接下载。

**示例 3：上传培养方案**

> 把培养方案（txt / markdown 等**文本类**文件）发给它，会识别里面哪些课有评价并逐门查询。注意：pdf / word 目前请把内容**粘贴**到对话框。

## 评价数据从哪来

- 数据来自**无穹书院课程评价系统**——同学们自发维护的公开评价库（10 分制自评），智能体**只读**访问，不会写入或修改任何数据。
- 当前覆盖**无穹书院培养方案课程**：秋季 10 门 / 春季 12 门 / 夏季 2 门。
- 评价是同学的主观体验，**样本有限、持续积累中**。样本不足 3 条的评分仅作参考，请以评论里的具体事实为准。
- **没有评价 ≠ 课程差**：新开课、新老师、冷门课往往没人评，此时建议试听第一周、问问上过的同学。
- 给分存在年际波动：去年的「调分大」不代表今年。
- **库外的课程查不到评价，它不会编造**——但可以和你聊选课方法论。

## 选课方法论速览

- **四维评估**：给分、工作量、讲课质量、实质收获。一条评论往往是混合的，它会帮你拆开看。
- **决策顺序**：必修/限选先落位 → 明确目标（保 GPA / 兴趣 / 求轻）→ 同一门课「老师 > 课程」，按老师粒度比较 → 核对上课时间不冲突。
- **押注分散**：一学期按「2 难 + 2 中 + 1 稳」搭配，别全押高难度或全押水课。
- **试听周**：前两周多试听再定，退改选窗口内保留调整余地（具体时间以教务通知为准）。

## 支持 / 不支持

| 能力 | 状态 |
|---|---|
| 文本对话、流式回答、思考过程 | ✅ |
| 多轮追问（学期 / 目标 / 已锁定课程） | ✅ |
| 多门课 / 多位老师横向对比 | ✅ 均分 + 样本 + 评论信号一张表 |
| 文本类文件输入（txt / markdown 等） | ✅ 直接读取并识别课程 |
| markdown 报告附件下载 | ✅ |
| pdf / word 文件 | 🟡 请把内容粘贴为文本 |
| 图片 / 音频 | 🟡 暂时看不了，用文字描述即可 |

## 常见问题

**Q：它会瞎编评价吗？**
不会。评价只能来自评价库，查不到就如实说「没有评价」，绝不编造分数或老师姓名。

**Q：推荐结果是最优解吗？**
不是。它给的是**证据 + 分目标建议**，最终选择权在你——同一个选择，求稳的人和想学东西的人答案不同。

**Q：数据多久更新一次？**
每次查询实时拉取评价库（带 5 分钟缓存），以最新评价为准。

**Q：对话会被保存吗？**
智能体为无状态设计，不保存对话全文；服务端仅记录会话 ID 与最近一次提问摘要用于排障。

## 安装到自己的 agent 客户端

想在自己的 agent 客户端（Claude Code、Cursor、Goose、OpenClaw 等支持 skill 机制的客户端）里直接用这个 skill？不需要部署服务——仓库里的 `skill/` 目录就是一份完整的 **skill 技能包**。

**环境要求**

| 依赖 | 要求 | 检查 | 安装 |
|---|---|---|---|
| Python | ≥ 3.9（脚本只用标准库） | `python3 --version` | [python.org](https://www.python.org) 或系统包管理器 |
| ripgrep（`rg`） | 客户端加载/索引 skill 时调用 | `rg --version` | Windows：`winget install BurntSushi.ripgrep.MSVC`；macOS：`brew install ripgrep`；Linux：`sudo apt install ripgrep` |
| 公网访问 | 评价数据挂在公开只读接口上 | 浏览器能打开课程评价系统页面 | — |

> **排查提示**：客户端加载 skill 报 `ripgrep execution failed` = 本机缺少 `rg`。按上表安装后重新加载即可；若客户端已在运行，重启客户端让 PATH 生效。

**安装步骤**

1. 下载 Releases 中的最新版本 `qingxiaoda-course-agent.zip`，将压缩包中的所有内容拷贝到客户端的技能目录，**目录名必须与 `SKILL.md` 里的 `name` 一致**

2. 确认拷贝后结构完整：

   ```
   course-selection-guide/
   ├── SKILL.md                         # 技能定义（name/description 决定何时触发）
   ├── scripts/query_evals.py           # 评价库只读查询脚本（标准库，零依赖）
   ├── references/selection-methods.md  # 选课方法论知识库
   └── assets/course-catalog.json       # 培养方案课程目录
   ```

3. 验证（两种方式任选）：
   - 直接跑脚本自检环境：`python3 skill/scripts/query_evals.py --summary`（Windows 用 `python`），应输出库内课程评价总览；
   - 在客户端里问「帮我选课」或「微积分哪个老师好」，应触发本 skill 并返回真实评价数据（均分、样本、评论信号）。

**可选配置（环境变量，不配则用默认值）**

| 变量 | 说明 |
|---|---|
| `COURSE_EVAL_URL` | 覆盖评价库接口地址（如自建镜像 / 代理时） |
| `COURSE_EVAL_KEY` | 覆盖只读凭据（默认用站点公开的只读 anon key） |

**注意事项**

- 脚本**只做只读查询**，不写入任何数据，也不输出评价者身份信息
- 评价库不可达时脚本会明确报错，`SKILL.md` 要求如实转述并转方法论建议——**不要编造评分**
- 更新：`git pull` 后重新拷贝 `skill/` 覆盖即可，skill 包与仓库版本保持同步
